# Third-Party Services

## vlrggapi

This project can run `axsddlr/vlrggapi` as an optional local Docker service for
VLR event discovery and structured match-detail ingestion.

- Repository: https://github.com/axsddlr/vlrggapi
- Pinned commit: `a6075fec9757ae5394c9a50002ba40270f4a5d00`
- License: MIT

The third-party source is fetched by Docker and is not copied into this
repository. Tier classification, validation, storage, training, and prediction
remain part of this project.
